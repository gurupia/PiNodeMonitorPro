📨 텔레그램 무료 알림 설정 가이드

Pi Node Monitor Pro는 텔레그램 봇(Bot) 기능을 이용해 평생 무료로 상태 알림 메시지를 보내드립니다.
아래의 3단계만 따라 하시면 입금 내역과 노드 장애 알림을 스마트폰으로 즉시 받아보실 수 있습니다.

1나만의 봇 만들기 (Bot Token)

텔레그램에서 나에게 메시지를 보내줄 로봇을 만드는 과정입니다.

  1. 텔레그램 앱을 실행하고 검색창에 @BotFather를 검색합니다. (파란색 인증 마크 확인)
  2. 대화방에 들어가서 /newbot 이라고 입력하고 전송합니다.
  3. 봇의 이름을 지어달라고 합니다. 아무거나 입력하세요. (예: MyPiNodeAlert)
  4. 봇의 아이디(Username)를 지어달라고 합니다. 반드시 끝이 bot으로 끝나야 합니다. (예: gurupia_pi_bot)
  5. 성공하면 긴 HTTP API Token이 발급됩니다. 이 값을 복사해 두세요.
Use this token to access the HTTP API:
123456789:ABCdefGHIjklMNOpqrsTUVwxyz

2내 채팅방 ID 알아내기 (Chat ID)

봇이 메시지를 보낼 "목적지(내 채팅방)" 주소를 알아내는 과정입니다.

💡 가장 쉬운 방법 (추천)
1. 텔레그램 검색창에 @userinfobot을 검색하세요.
2. 대화방에 들어가서 아무 메시지나 보내세요.
3. 답장으로 오는 Id: 12345678 부분의 숫자가 내 Chat ID입니다.

3프로그램에 입력하기

  1. Pi Node Monitor Pro 프로그램의 설정(Settings) 버튼을 누릅니다.
  2. 상단의 [Telegram (Free)] 탭을 클릭합니다.
  3. Enable Telegram Notifications 체크박스를 켭니다.
  4. Bot Token 칸에 1단계에서 받은 값을 붙여넣습니다.
  5. Chat ID 칸에 2단계에서 받은 숫자를 붙여넣습니다.
  6. [📨 Test] 버튼을 눌러 내 폰으로 메시지가 오는지 확인합니다.
  7. 메시지가 잘 오면 [💾 Save All] 버튼을 눌러 저장합니다.

🎉 이제 PC가 켜져 있는 한 24시간 입금 및 노드 상태를 감시해 드립니다.
