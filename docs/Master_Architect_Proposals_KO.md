# 마스터 시스템 아키텍트: 프로젝트 개선 제안서

본 문서는 Pi Node Monitor 프로젝트의 현재 상태를 기반으로, 마스터 시스템 아키텍트가 제안하는 4가지 핵심 기술적 도약 방안을 상세히 설명합니다.

---

## 1. Cloudflare Tunnel 자동 통합 (연결성/보안)
- **배경**: 현재 모바일 서버 접속은 공유기의 포트포워딩 설정에 의존하여 사용자 환경마다 접속 성공률이 일정하지 않음.
- **상세 제안**: `CloudflareTunnelService.cs`를 활성화하여 서버 시작 시 `cloudflared` 바이너리를 통해 일시적인 보안 터널(trycloudflare.com)을 자동 생성.
- **장점**: 
    - 포트포워딩 불필요 (NAT 환경 완전 극복)
    - SSL/TLS 암호화 기본 제공
    - 공개 IP 노출 최소화로 보안성 향상

## 2. 보너스 트렌드 시각화 (데이터 분석)
- **배경**: `Bonus_History.csv`에 축적되는 양질의 데이터를 단발성 수치 확인용으로만 사용 중.
- **상세 제안**: 누적 데이터를 분석하여 대시보드 내에 '최근 7일 보너스 변동 차트' 또는 '최고 기록 알림' 기능 추가.
- **장점**:
    - 노드 가용성(Availability) 변화를 시각적으로 감지
    - 환경 변화(네트워크 교체, 정전 등)에 따른 수익성 영향도 파악 용이

## 3. 정적 타입 기반 API 모델링 (안정성)
- **배경**: `WalletService` 및 `BonusService`가 정규표현식이나 단순 문자열 매칭으로 외부 API 데이터를 처리하고 있어, API 변경 시 런타임 에러에 취약.
- **상세 제안**: `Newtonsoft.Json` 라이브러리를 충분히 활용하여 API 응답에 대한 DTO(Data Transfer Object) 클래스 정의 및 역직렬화 적용.
- **장점**:
    - 코드 가독성 및 유지보수 편의성 증대
    - 타입 안정성 확보로 인한 잠재적 크래시 방지

## 4. i5-14600K 하이브리드 최적화 (성능)
- **배경**: 14세대 코어 프로세서의 P-core(성능)와 E-core(효율) 구조를 고려한 스레드 할당 전략 부재.
- **상세 제안**: 핵심 모니터링 루프와 화면 캡처 작업 시 `SetThreadAffinityMask` 또는 프로세서 그룹 관리를 통해 중요 작업을 P-core에 고정하는 최적화 모드 제공.
- **장점**:
    - 백그라운드 작업으로 인한 UI 랙 현상 원천 차단
    - 프리미엄 CPU의 자원을 최적으로 활용하여 응답 시간(Latency) 최소화
